## 4. สิ่งที่ต้องพัฒนาเพิ่มในเว็บ class-arena-spark

### 4.1 ปัญหา: ไม่มี UI ให้ครูตรวจ essay ด้วยมือ
DB enum `graded_by` รองรับ `'teacher'` อยู่แล้ว (migration `20260716090200_exam_student_rpcs.sql`) แต่ **ไม่มี UI** ในหน้า report ให้ครูเห็นคำตอบเด็กแล้วปรับคะแนนได้

**Solution:** เพิ่ม section "ตรวจข้อเขียนด้วยมือ" ใน `src/routes/_authenticated/exam.$examId.report.tsx`
- แสดงตาราง: นักเรียน × ข้อ short_answer ที่ยังไม่ได้ตรวจหรือ AI ตรวจแล้ว
- ครูคลิก → เห็น `answer_text` เต็ม + คำถาม + `expected_answer` (ถ้ามี) + คะแนนที่ AI ให้
- ครูปรับ `score_awarded` + กด save → เรียก RPC `grade_short_answer(_graded_by:='teacher')`
- อัปเดต `total_score` ของ `exam_participants` ใหม่

### 4.2 ปัญหา: Textarea สั้นเกินไปสำหรับ essay
UI ปัจจุบันใช้ `<Textarea rows={3}>` ใน `src/routes/_authenticated/exam.$examId.tsx` (สำหรับ short_answer ทุกข้อ) — ไม่พอเขียน essay ความยาว 1 ย่อหน้า

**Solution:** ขยายเป็น `rows={8}` สำหรับทุกข้อ short_answer (UI เดียวกัน ไม่ต้องแยกประเภท essay)

### 4.3 ไม่ต้องเปลี่ยน DB schema
- `question_type` CHECK constraint ยังคงเป็น `'multiple_choice' | 'short_answer'` (ไม่เพิ่ม `'essay'`)
- essay ใช้ `short_answer` + `Textarea rows=8` ธรรมดา แต่ตรวจด้วย `'teacher'` แทน `'ai'`
- ใน `exam_questions` ฟิลด์ `expected_answer` สำหรับ essay จะเก็บ "rubric/เกณฑ์การให้คะแนน" แทนคำตอบตายตัว เพื่อให้ครูเห็นตอนตรวจ

ข้อสอบทั้งสองวิชาจะสร้างผ่านหน้า **"สร้างข้อสอบ"** (`src/routes/_authenticated/exam.new.tsx`) ที่มีอยู่แล้ว — ไม่ต้องเขียน code เพิ่ม ครูกรอกใน UI ได้เลย

**โครงสร้างข้อมูล (เพื่อให้ครูเตรียมง่าย):**
- ม.3: 14 ข้อ (13 MC + 1 short_answer)
- ม.4: 11 ข้อ (9 MC + 2 short_answer)

รายละเอียดคำถามและตัวเลือกของแต่ละข้อ จะเขียนแยกใน implementation plan (ขั้นตอนถัดไป)

## 6. ขอบเขต (Scope) — สิ่งที่ทำและไม่ทำ

**จะทำ:**
1. เพิ่ม UI "ตรวจข้อเขียนด้วยมือ" ในหน้า report (Section 4.1)
2. ขยาย Textarea สำหรับ short_answer เป็น rows=8 (Section 4.2)
3. สร้างข้อสอบ ม.3 (Canva) 14 ข้อ: 13 MC + 1 short_answer (link Canva)
4. สร้างข้อสอบ ม.4 (เทคโนโลยี) 11 ข้อ: 9 MC + 2 short_answer (essay)
5. เตรียม Canva design link รายคนสำหรับเด็ก ม.3 (ครูทำเอง นอกระบบ)

**จะไม่ทำ (YAGNI):**
- ไม่เพิ่ม question_type `'essay'` ใหม่ — ใช้ short_answer อยู่
- ไม่เพิ่ม file upload — ใช้ short_answer เก็บ URL แทน
- ไม่เพิ่ม rubric field ใหม่ใน DB — เก็บใน `expected_answer`
- ไม่เปลี่ยน AI grading — ยังใช้ AI ตรวจ short_answer ข้อปกติ และให้ครูตรวจ essay ทับ

## 7. ความเสี่ยงและการบรรเทา

| ความเสี่ยง | การบรรเทา |
|---|---|
| guest editor ใน Canva อาจ save ไม่ได้ → งานเด็กหาย | บอกเด็ก "duplicate template ของตัวเอง" ก่อนเริ่ม และ download สำรอง PNG |
| AI ให้คะแนน essay ไม่แม่น → คะแนนเด็กผิด | ทุก essay ครูตรวจยืนยันด้วยมือ แทนที่คะแนน AI |
| เน็ตห้องเรียนไม่พอให้ทั้งห้องเปิด Canva พร้อมกัน | เตรียมข้อสอบ theory (ข้อ 1-13) ให้ทำได้แม้ไม่เปิด Canva ข้อ 14 จึงเป็น bonus |
| เด็กลืมวาง link Canva ในข้อ 14 | เตือนในคำถาม + ครูเช็คก่อนส่ง |
